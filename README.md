# .github

Default community health files for every erm-git repository that does not have its own
([GitHub docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)):

- `CONTRIBUTING.md`: how issues, labels, pull requests and agents work across all repositories.
- `SECURITY.md`: how to report security problems.
- `.github/ISSUE_TEMPLATE/`: issue forms (Finding, Task, Bug).
- `.github/pull_request_template.md`: pull request template.

A repository that has its own file of the same kind uses its own instead. Each repository
keeps its own `README.md` and `AGENTS.md`.
